# Legacy v1 source

This directory preserves the original endpoint-shaped tools and disconnected
demo UIs for historical reference. It is excluded from the active build.

The v1 implementation is not production-ready: several routes no longer match
the official Toast API, HTTP tool execution was a placeholder, and the UI used
demo data without MCP App resource wiring. Do not copy these modules into the
v2 runtime without checking the current Toast contract.
